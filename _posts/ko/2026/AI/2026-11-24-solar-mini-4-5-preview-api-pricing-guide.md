**Solar Mini 4.5 Preview는 한국어 업무 자동화와 도구 호출을 시험해 볼 수 있는 업스테이지의 새 미리보기 모델입니다.** 현재 할인 단가로 작은 평가를 시작할 수 있지만, Preview 모델 종료가 예정되어 있어 운영 서비스에 연결할 때는 교체 계획을 함께 준비하셔야 합니다.

업스테이지 [변경 이력][changes]과 [모델 문서][model]는 **2026년 11월 23일** 공개를 기록합니다. 이 글은 **11월 24일 한국 시간에 확인한 공식 자료**를 기준으로 정리했습니다.

## 핵심 요약

- 모델 식별자는 `solar-mini-4-5-preview`입니다.
- 채팅·추론·구조화 출력·도구 호출을 지원합니다.
- 공식 문서는 **11월 30일 Preview 종료**, **12월 1일 Solar Mini 4.5 정식 출시 예정**을 안내합니다.
- 현재 API 단가와 앞으로의 정식 모델 요금을 구분해 판단해야 합니다.

12월 1일은 **예정일**입니다. 정식 버전의 실제 제공 여부와 최종 사양은 해당 날짜에 다시 확인하셔야 합니다. 공식 문서에서 종료 시각과 기준 시간대는 확인하지 못했으므로, 11월 30일 늦은 시각까지 사용할 수 있다고 가정하지 않는 편이 좋습니다.

## Solar Mini 4와 무엇이 달라졌나요?

[기존 Solar Mini 4 문서][previous]와 [Preview 문서][model]를 비교하면, 모델 규모와 문맥 길이가 크게 바뀌었다기보다 같은 규모에서 에이전트 성능 개선을 내세운 업데이트입니다.

| 항목 | Solar Mini 4 | Solar Mini 4.5 Preview |
|---|---|---|
| 공개일 | 2026년 9월 22일 | 2026년 11월 23일 |
| 전체 / 활성 파라미터 | 35B / 3B | 35B / 3B |
| 문맥 길이 | 512K | 512K |
| 최대 출력 | 128K 토큰 | 128K 토큰 |
| 학습 데이터 기준 | 2026년 2월 | 2026년 8월 |
| 한국어·영어·일본어 입출력 | 지원 안내 | 지원 안내 |
| 이용 단계 | 기존 제공 모델 | 종료 일정이 있는 Preview |

B는 10억 단위입니다. 활성 파라미터가 적다는 수치만으로 우리 서비스의 지연 시간이나 처리량을 계산할 수는 없습니다.

업스테이지는 Preview에서 에이전트 성능이 개선됐다고 설명합니다. 이 글에서는 독립적으로 성능을 측정하지 않았으므로, 기존 모델보다 모든 업무에서 우수하다고 단정하지 않습니다. 학습 데이터 기준일이 최근으로 이동했다는 사실도 오늘의 최신 정보까지 안다는 뜻은 아닙니다.

## 현재 API 가격은 얼마인가요?

아래는 **2026년 11월 24일 확인한 미국 달러(USD) 기준, 100만 토큰당 API 요금**입니다. 입력·캐시 입력·출력을 구분했습니다. 챗봇 월 구독료가 아닙니다.

| 구분 | Preview 현재 단가 | 문서에 표시된 정가 |
|---|---:|---:|
| 일반 입력 | $0.01 / 1M 토큰 | $0.10 / 1M 토큰 |
| 캐시 입력 | $0.001 / 1M 토큰 | $0.01 / 1M 토큰 |
| 출력 | $0.04 / 1M 토큰 | $0.40 / 1M 토큰 |

[모델 문서][model]는 90% 할인이라고 안내하며, [공식 API 가격표][pricing]에서도 현재 할인 단가를 확인할 수 있습니다. 가격표는 부가가치세 10% 별도라고 명시합니다.

정식 모델이 실제로 어떤 조건과 단가로 제공될지는 출시 시점에 확인하십시오. **현재 할인액을 장기 운영 비용으로 고정해서 계산하지 않는 것**이 중요합니다.

### 작은 평가의 비용을 계산해 보면

예를 들어 캐시를 쓰지 않고 **입력 합계 100만 토큰, 출력 합계 20만 토큰**을 사용했다고 가정하겠습니다.

- 입력: 1 × $0.01 = **$0.01**
- 출력: 0.2 × $0.04 = **$0.008**
- 합계: **$0.018**, 부가세 등 별도

같은 사용량을 위 표의 정가로 계산하면 **$0.18**입니다. 이는 단가 차이를 이해하기 위한 계산이며 실제 사용 기록이나 정식 출시 후 청구액 예측은 아닙니다.

재시도와 도구 실행 뒤의 추가 모델 호출도 사용량을 늘릴 수 있습니다. 요청 건수만 세기보다 응답의 토큰 사용량을 합산해 비교하셔야 합니다.

## 누구에게 유용하고, 무엇을 시험해야 하나요?

한국어 문의를 분류하거나, 정해진 형식으로 답을 만들거나, 업무 API를 고르는 기능을 개발하는 분이라면 평가 후보로 삼을 만합니다.

다만 모델이 도구 호출을 지원한다는 것과 업무 자동화가 완성됐다는 것은 다릅니다. [업스테이지 도구 호출 안내][tools]의 흐름은 모델이 요청한 함수를 애플리케이션이 실행하고, 결과를 다시 모델에 전달하는 방식입니다.

예를 들어 주문 상태를 조회하는 서비스라면 확인할 지점은 다음과 같습니다.

| 단계 | 평가할 내용 |
|---|---|
| 요청 이해 | 주문 조회와 취소 요청을 구분하는가 |
| 도구 선택 | 조회 질문에 맞는 함수를 선택하는가 |
| 인자 생성 | 주문 번호를 원문대로 전달하는가 |
| 실행 처리 | 없는 주문·API 오류를 처리하는가 |
| 최종 답변 | 도구 결과에 없는 상태를 만들어내지 않는가 |

이는 공식 벤치마크가 아닌 **개발 평가를 위한 제안**입니다. 모델의 답변 문장만 보면 잘못된 도구 선택이나 인자 오류를 놓치기 쉽습니다.

처음에는 읽기 전용 조회 작업으로 시험하고, 같은 입력을 기존 모델에도 제공해 보십시오. 정답률 외에 재시도 횟수, 응답 시간, 출력 토큰, 사람이 수정한 시간을 함께 기록하면 선택 근거가 생깁니다.

## 지금 이용하는 방법

공식 모델 페이지는 Console과 Playground 이용을 안내하고, Playground는 API 키 없이 무료로 체험할 수 있다고 설명합니다. **Playground 무료 체험과 유료 API 호출은 구분**하셔야 합니다.

권장 시작 순서는 다음과 같습니다.

1. [모델 페이지][model]에서 Preview 상태와 식별자를 확인합니다.
2. 페이지의 Playground 링크에서 한국어 예시 질문으로 응답 형식을 살펴봅니다.
3. API 연결이 필요하면 [시작 안내][start]에 따라 계정과 API 키를 준비합니다.
4. 공개 가능하거나 사용 승인을 받은 평가 자료로 소규모 비교를 진행합니다.
5. 정식 출시 전에 모델 교체 후 다시 실행할 평가 목록을 보관합니다.

API 키는 소스 저장소에 넣지 말고 환경변수 등으로 관리하십시오. 이 글에서는 실제 계정 접속·결제·API 호출을 수행하지 않았습니다. 한국어 입출력 지원은 공식 확인 내용이지만, 한국 계정의 가입과 결제 조건을 직접 검증했다는 뜻은 아닙니다.

## Preview 종료 전에 준비할 것

이번 버전을 시험 환경에 연결할 때는 모델 식별자를 코드 여러 곳에 흩어 놓기보다 설정으로 관리하는 편이 좋습니다. 종료 이후의 대체 모델명이나 자동 전환을 가정하지 말고, 정식 출시 공지를 확인해 변경하십시오.

평가 자료에는 입력 질문뿐 아니라 기대 출력, 허용할 도구, 실제 응답, 사용 토큰을 함께 남기십시오. 정식 버전으로 바뀐 뒤 같은 자료를 다시 실행해야 개선 여부와 회귀 문제를 구분할 수 있습니다.

**지금은 작은 업무를 비교할 시점이며, 장기 운영 결정은 정식 사양과 요금 확인까지 이어져야 합니다.** 할인 폭보다 내 업무의 오류율과 운영 조건을 판단 기준으로 삼으시면 됩니다.

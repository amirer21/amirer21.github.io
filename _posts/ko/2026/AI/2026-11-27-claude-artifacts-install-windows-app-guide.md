**Claude에서 만든 작은 도구를 Windows·Mac의 별도 창과 아이콘으로 열 수 있게 됐습니다.** ‘Install as app’ 기능을 쓰면 아티팩트를 앱처럼 설치할 수 있습니다. 다만 실행에는 Claude 로그인과 인터넷 연결이 필요하므로, 설치 여부와 오프라인 실행 가능 여부를 구분하셔야 합니다.

Anthropic의 [공식 발표일은 2026년 11월 24일][release]입니다. 이 글은 **11월 27일 한국 시간에 확인한 공식 자료**를 기준으로 설치 방법과 선택 기준을 정리합니다. 직접 설치하거나 기능을 시험한 체험기는 아닙니다.

## 무엇이 달라졌나요?

[공식 발표][release]는 아티팩트를 별도 데스크톱 앱으로 설치하고 공유하는 기능을 소개합니다. 설치된 앱에는 아이콘과 창이 생기며, 사용자가 허용한 범위에서 알림이나 운영체제 기능을 이용할 수 있습니다.

먼저 아티팩트가 무엇인지 구분하면 이해하기 쉽습니다. [기본 안내][basics]에서 아티팩트는 Claude가 만드는 문서·화면·대시보드·작은 대화형 도구처럼, 대화 옆에서 열고 수정하거나 재사용할 수 있는 결과물입니다.

이번 기능은 그중 설치 가능한 결과물을 자주 쓰는 도구로 꺼내 쓰는 방식입니다. 설치했다고 원래 아티팩트와 분리되는 것은 아닙니다. 원본이 수정되면 앱에도 반영된다고 공식 문서는 설명합니다.

## 어떤 작은 도구부터 만들면 좋을까요?

다음은 제품 시연 결과가 아닌 **첫 실험을 위한 제안**입니다.

| 필요한 일 | 시작하기 좋은 도구 | 확인할 결과 |
|---|---|---|
| 집중 시간 관리 | 시작·일시정지가 있는 타이머 | 정지·재시작이 정확한가 |
| 로그 가독성 개선 | 붙여넣은 JSON을 정렬하는 도구 | 잘못된 JSON을 구분하는가 |
| 반복 작업 준비 | 작업 전 확인 목록 | 항목을 빠뜨리지 않고 표시하는가 |
| 파일 이름 변경 | 변경 전후 이름 미리보기 | 실제 변경 전에 차이를 볼 수 있는가 |

처음에는 입력과 결과를 눈으로 비교할 수 있는 작은 기능이 적합합니다. 예를 들어 파일 이름 도구를 만들더라도, 실제 파일 변경보다 **새 이름을 제안하는 미리보기**부터 구현하면 규칙의 오류를 발견하기 쉽습니다.

요청도 구체적으로 작성하십시오.

> 붙여넣은 JSON을 읽기 좋게 정렬하는 작은 아티팩트를 만들어 주세요. 유효하지 않은 입력에는 오류 위치를 보여 주세요. 원본 입력을 지우지 말고, 정렬된 결과를 복사하는 버튼을 넣어 주세요.

이는 그대로 요청해 볼 수 있는 예시이며 결과의 정확성을 보증하는 명령은 아닙니다. 정상 입력뿐 아니라 빈 입력, 잘못된 괄호, 큰 입력도 직접 확인하셔야 합니다.

## Windows에서 설치하는 순서

[최신 도움말][install]은 **Claude Desktop 6.28899.0 이상**을 안내합니다. 기능은 Free·Pro·Max·Ultra·Team·Enterprise 플랜에 베타로 순차 제공됩니다.

설치 절차는 다음과 같습니다.

1. Claude Desktop의 주 창에서 설치할 아티팩트를 엽니다.
2. 아티팩트 제목 메뉴를 열거나 아티팩트를 오른쪽 클릭합니다.
3. **Install as app**을 선택합니다. Share 메뉴에서도 찾을 수 있습니다.
4. **Install**을 눌러 설치를 확인합니다.

Windows에서는 시작 메뉴의 **Claude Apps** 폴더나 바탕화면 바로가기로 실행할 수 있습니다. 메뉴가 보이지 않으면 앱 버전과 조직의 기능 허용 상태, 해당 아티팩트의 설치 가능 여부를 확인하십시오.

공식 도움말은 Linux·웹·모바일 설치를 지원하지 않는다고 안내합니다. Docs·Slides·Sheets 같은 템플릿 결과물도 설치할 수 없는 대상에 포함됩니다. 아티팩트가 열린다는 사실만으로 앱 설치까지 지원된다고 판단해서는 안 됩니다.

## 권한은 작업에 맞게 선택하세요

[발표 문서][release]는 기본 동작, 개별 앱 권한, 전체 컴퓨터 접근을 구분합니다.

| 범위 | 의미 |
|---|---|
| 기본 | 브라우저 안에서 할 수 있는 범위의 동작 |
| 앱 권한 | 알림·단축키·다른 창 위 표시 같은 기능 요청 |
| 전체 컴퓨터 접근 | 프로그램 실행과 파일 읽기·수정·삭제까지 가능한 범위 |

JSON 정렬 도구라면 파일 전체 접근이 꼭 필요한지부터 판단하십시오. 반대로 폴더의 파일을 실제로 변경하는 도구라면, 미리보기와 실패 시 처리 방법까지 검토할 필요가 있습니다.

공식 발표는 앱 버전이 바뀌면 권한을 다시 요청하며, 외부 사이트에서 불러온 부분은 별도 재요청 없이 바뀔 수 있다고 설명합니다. 따라서 설치 시 한 번 확인하는 것뿐 아니라 **수정 후에도 같은 작업 범위인지** 살펴보는 것이 좋습니다.

Windows에서 권한을 바꾸려면 [도움말][install]에 따라 앱 제목 표시줄을 오른쪽 클릭하거나 Alt+Space를 누른 뒤 **Permissions**를 선택합니다. 권한을 해제해도 이미 바뀐 파일이 자동 복구되는 것은 아닙니다.

## 회사 계정에서 메뉴가 보이지 않는다면

[조직 관리자 안내][admin]는 Team에서 앱 설치가 기본 활성화되고, Enterprise에서는 기본 비활성화된다고 설명합니다. 전체 컴퓨터 접근은 두 플랜 모두 기본적으로 꺼져 있습니다.

조직 설정과 기기 관리 정책이 다르면 더 엄격한 설정이 적용됩니다. 회사 계정에서는 개인 PC에서 보이는 메뉴와 다를 수 있으므로, 앱 업데이트만 반복하기보다 관리자의 Artifacts 설정을 확인하는 편이 좋습니다.

이 글에서는 회사 계정의 설정을 변경하거나 국내 계정의 실제 접속·설치를 검증하지 않았습니다. 공식 문서의 제공 범위를 한국의 모든 계정에서 즉시 이용 가능하다는 뜻으로 확대하지 않았습니다.

## 비용과 실행 조건을 어떻게 판단해야 하나요?

[공식 발표][release]는 앱이 Claude에 보내는 요청이 기존 플랜 사용량에 포함된다고 안내합니다. 앱으로 설치했다고 Claude 호출이 무제한이 되는 것은 아닙니다. 이 글은 별도 API 가격이나 예상 월 비용을 산정하지 않습니다.

[도움말][install]은 앱을 열 때 온라인 상태로 Claude Desktop에 로그인해야 한다고 명시합니다. 인터넷 없이 실행해야 하는 업무라면 먼저 이 조건이 맞는지 확인하셔야 합니다.

도구 선택은 다음 기준으로 판단해 보십시오.

- **반복해서 여는 작은 개인 도구:** 설치형 아티팩트의 편의성을 시험해 볼 만합니다.
- **복잡한 저장소 수정과 테스트:** 코드·실행 환경·변경 검토를 다루는 개발 도구가 더 적합할 수 있습니다.
- **연결이 끊겨도 반드시 작동해야 하는 업무:** 오프라인 요구 사항을 충족하는 다른 실행 방식을 검토해야 합니다.

첫 사용의 목표는 큰 앱을 한 번에 만드는 것보다, 매일 반복하는 작은 작업 하나를 줄이는 것입니다. 입력·출력·권한·실행 조건이 분명한 도구로 시작하면 유용성과 한계를 함께 판단하기 쉽습니다.
